# IR Beacon

This repository contains development material for the IR beacon project. The
`product/` directory is the complete published representation of the GISC
product OSB-1.

During publication, the target directory `src/products/osb-1/` in the
`gisc-website` repository is fully replaced by the contents of `product/`.
Files not present in `product/` must therefore be removed from the published
product.
